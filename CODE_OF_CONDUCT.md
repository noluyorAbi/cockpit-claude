# Code of Conduct

## The short version

Be decent. Argue with the code, not with the person who wrote it.

This is a small project. It does not need a bureaucracy, but it does need people to
know what happens if something goes wrong, so here it is in plain terms.

## Expected

- Assume the other person is competent and acting in good faith until you have
  actual evidence otherwise.
- Criticise decisions, designs and code freely. "This projection is wrong under
  bursty load" is welcome. "You clearly do not understand statistics" is not.
- Accept that maintainer time is finite and that "no" is a complete answer to a
  feature request.
- Respect that people write in a second language, work in a different timezone, and
  have jobs.

## Not accepted

- Harassment, sexualised language or imagery, and personal or political attacks.
- Insults, deliberate intimidation, and sustained disruption of a discussion.
- Publishing anyone's private information without their explicit permission.
- Any conduct that would obviously be inappropriate in a professional setting.

## Scope

This applies to everything in this project's spaces: issues, pull requests,
discussions, commit messages, and the comment thread on the website. It also applies
when you are representing the project in public.

## Enforcement

Report to `alperen@adatepe.dev`. Reports are handled privately and the reporter's
identity stays between them and the maintainer.

There is one maintainer, so there is no appeals committee. Depending on severity,
the response is a private word, an edited or removed comment, a temporary block, or a
permanent ban. Serious or repeated behaviour goes straight to the last one.
